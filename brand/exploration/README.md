# Logo exploration

Open any file in a browser. Each round shows the marks at display size, on a tile, at 16 px, and in the lockup.

- `round-1-cursive.html`: single-stroke cursive ℓ. Variant F became the current mark.
- `round-2-styles.html`: three other directions: rigid cursive, faceted ribbon, nib monogram.
- `round-3-revised.html`: rigid and faceted redrawn with the crossing moved low so they read as ℓ rather than a numeral 4, with F and the nib monogram for comparison.
