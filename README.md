# longhand-site

The public face of [Longhand](https://github.com/Longhand-io/longhand): the website, the brand, and shared resources.

- `index.html`: the landing page, served by GitHub Pages at https://longhand-io.github.io/longhand-site/
- `brand/`: logo files, colours, type, and voice. Start with [brand/README.md](brand/README.md).
- `assets/`: files the site loads.

The plugin and spec live in [longhand](https://github.com/Longhand-io/longhand). The importer lives in [scrivener-to-obsidian](https://github.com/Longhand-io/scrivener-to-obsidian).
