# longhand-site

The public face of [Longhand](https://github.com/grassclaw/longhand): the website, the brand, and shared resources.

- `index.html`: the landing page, served by GitHub Pages at https://grassclaw.github.io/longhand-site/
- `brand/`: logo files, colours, type, and voice. Start with [brand/README.md](brand/README.md).
- `assets/`: files the site loads.

The plugin and spec live in [longhand](https://github.com/grassclaw/longhand). The importer lives in [scrivener-to-obsidian](https://github.com/grassclaw/scrivener-to-obsidian).

Longhand is independent and not affiliated with or endorsed by Literature & Latte, the makers of Scrivener, or by Obsidian.
